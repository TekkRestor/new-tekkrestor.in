# TekkRestor Design System

## Typography
- Primary font: Roboto (Google Fonts), with Arial/sans-serif fallback.
- Headings: Roboto 700; hero headline 800. Use compact but readable tracking, not excessively tight letter spacing.
- Body: Roboto 400/500; navigation and controls 500–700.

## Colour palette
- Primary blue: `#1264A3`
- Deep navy: `#102A43`
- Teal: `#0B8F87`
- Sustainability green: `#16865B`
- Text: `#172B3A`
- Muted text: `#536574`
- Soft background: `#F3F7FA`
- Borders: `#DCE5EB`

## Typography hierarchy
- H1: bold Roboto, responsive 2.35rem–4.35rem, line-height about 1.08.
- H2: Roboto 700, responsive 1.95rem–2.8rem, line-height about 1.18.
- H3/cards: Roboto 700, around 1.1rem.
- Body copy: Roboto 400, line-height 1.65–1.75.

## Components
Use white space, clear blue CTA buttons, restrained teal/green accents, responsive cards, visible keyboard focus and reduced-motion support.
